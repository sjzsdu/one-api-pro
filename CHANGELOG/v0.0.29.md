# v0.0.29 — 2026-11-25

> 模型别名池与会话亲和、原生多模态网关（图像/语音/重排/视频/实时），以及覆盖同步与异步推理的预留—结算—对账体系。

## 中文

### ✨ 新增功能

- **模型别名与模型池**：在「设置 → 个人 → 模型别名与模型池」配置个人别名，超级管理员可发布全局别名。单个别名最多 8 个候选模型，权重 1–1000，新会话按权重分配；支持 `X-Session-ID` 显式会话、基于消息历史的自动前缀识别、会话空闲 TTL、Redis 共享绑定与池内故障切换。日志同时保留业务别名与实际上游模型。
- **原生多模态网关**：新增 `wan2.6-t2i` 文生图、Wan2.7 图像编辑、`seed-tts-2.0` 语音合成、`qwen3-asr-flash` 原生语音识别、`gte-rerank-v2` 重排与 `wan2.6-t2v` 异步视频生成；Qwen Omni 双向实时语音通过 WebSocket 协议子集接入。网关按“操作 + 执行模式”选择渠道，能力目录与渠道实际能力取交集。
- **推理作业与持久账务**：同步与异步推理统一走额度预留 → 真实用量结算。新增 `GET /v1/inferences/:id` 查询原请求、`X-Inference-Id` 关联、未知执行结果保留待对账，以及普通请求、视频任务、实时会话三类管理员对账接口。
- **媒体资产与 worker**：视频资产落地本地目录，7 天有效期、单文件上限 512 MiB；worker 负责任务轮询、退避重试、资产清理与过期会话标记，多实例通过 SQL 租约协作。
- **控制台媒体探针调试台**：图像/音频渠道可直接在控制台发起探测，探测记录管理员、操作、渠道与用量审计，不记录媒体 URL 与密钥。
- **渠道模型目录与映射**：渠道可声明默认模型与模型目录，支持模型映射（`catalog_model_name` 指向真实目标）；wildcard 令牌模型展开为具体分组模型；启动时按渠道对账 ability，分组名从价格/渠道/用户合并真实名称。
- **可解释的路由失败诊断**：渠道失败返回具体诊断原因，可直接区分权限、能力、地域与上游错误。

### 🐛 问题修复

- 管理仪表盘聚合查询改用方言感知的条件计数与标识符引用，修复 PostgreSQL / SQLite 下保留字与布尔 `SUM` 表达式报错。
- 简化非管理员账号的模型别名作用域处理，避免错误暴露全局配置入口。
- 修正目录页模型与渠道列展示顺序，补齐使用示例与预置渠道模型清单。

### 📚 文档

- 文档站新增「多模态与媒体」分类（总览、图像/语音/重排、视频/实时语音、账务结算与巡检）与「模型别名与模型池」页面，均为中英双语。
- API 总览新增“多模态与媒体接口”索引；补齐 v0.0.28 发布日志。

### ⚠️ 升级注意事项

- 无数据库结构变更，无需执行迁移脚本。
- 多实例部署时，API 与 worker 必须挂载**同一个**媒体资产目录共享卷，否则视频资产不可读。
- 新增价格按“每百万计量单位”配置：视频/ASR 以秒计价时需换算（0.00022 元/秒 = 每百万秒 220 元），不能直接填 0.00022。
- 视频任务必须提供 `Idempotency-Key`；实时语音是 Qwen 手动轮次协议子集，不保证兼容所有 OpenAI realtime 客户端。
- 别名池权重是会话分配比例，不是 Token 或采购金额比例，也不保证供应商提示词缓存命中。

## English

### ✨ New Features

- **Model aliases and pools**: configure personal aliases under Settings → Personal → Model aliases and pools; a super admin can publish global aliases. Each alias holds up to 8 candidates with weights 1–1000, picked by weight for new sessions. Supports explicit `X-Session-ID`, automatic message-history prefix recognition, idle session TTL, Redis-shared bindings and pool failover. Logs keep both the business alias and the actual upstream model.
- **Native multimodal gateway**: `wan2.6-t2i` text-to-image, Wan2.7 image editing, `seed-tts-2.0` TTS, `qwen3-asr-flash` native ASR, `gte-rerank-v2` rerank and `wan2.6-t2v` async video generation, plus a Qwen Omni bidirectional realtime WebSocket protocol subset. Channels are selected by operation + execution mode, and requests run on the intersection of catalog capability and adapter capability.
- **Inference jobs and persistent billing**: sync and async inference share reserve → settle-on-real-usage accounting, with `GET /v1/inferences/:id` lookup, `X-Inference-Id` correlation, reservations kept for unknown outcomes, and admin reconciliation for plain requests, video jobs and realtime sessions.
- **Media assets and worker**: video assets land in a local directory, valid 7 days with a 512 MiB per-file cap; the worker polls jobs, backs off, cleans assets and marks stale sessions, coordinating across instances via SQL leases.
- **In-console media probe**: probe image/audio channels from the console, recording admin, operation, channel and usage audit — never media URLs or keys.
- **Channel model catalog and mapping**: channels declare default models and a catalog, support model mapping (`catalog_model_name` pointing to a real target); wildcard token models expand to concrete group models; abilities reconcile from channels on startup, and group names merge real names from pricing/channels/users.
- **Explainable routing failures**: channel failures return specific diagnostic reasons, distinguishing permission, capability, region and upstream causes.

### 🐛 Bug Fixes

- Admin dashboard aggregates now use dialect-aware conditional counts and identifier quoting, fixing reserved-word and boolean `SUM` failures on PostgreSQL / SQLite.
- Model alias scope handling for non-admin accounts simplified, so the global entry is never exposed incorrectly.
- Catalog column ordering, usage examples and preset channel model lists corrected.

### 📚 Documentation

- New doc-site category "Multimodal & Media" (overview, image/audio/rerank, video/realtime, settlement & probes) and a "Model Aliases and Pools" page, both bilingual.
- API overview gains a multimodal and media endpoint index; v0.0.28 release notes added.

### ⚠️ Upgrade Notes

- No schema change and no migration script.
- With multiple instances, API and worker must mount the **same** shared media asset volume, or video assets become unreadable.
- New prices are configured per million metering units: second-billed video/ASR must be converted (0.00022 CNY/second = 220 CNY per million seconds), never entered as 0.00022.
- Video jobs require an `Idempotency-Key`; realtime voice is a Qwen manual-turn protocol subset and is not guaranteed compatible with every OpenAI realtime client.
- Alias weights are a session allocation ratio, not a token or spend ratio, and do not guarantee provider prompt-cache hits.
