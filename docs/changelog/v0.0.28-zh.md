### ✨ 新增功能

- **CI 双推镜像**：`release-docker.yml` 同时推送 `ghcr.io/<repository>` 与 `sjzsdu/one-api-pro`，`linux/amd64` + `linux/arm64`，保留 semver 标签与 `latest`；新增镜像与 git tag 同名的 `v0.0.28` 标签。
- **`INITIAL_ROOT_PASSWORD`**：首次启动时用该环境变量创建 root 密码。
- **注册开关环境变量**：`REGISTER_ENABLED` / `PASSWORD_REGISTER_ENABLED` 默认仍为 `true`，显式设置后由环境变量接管，数据库 option 无法覆盖回开启状态。
- **`SESSION_SECRET` 启动告警**：未设置时打 WARN，提示重启会导致所有会话失效。
- **`make docker-build`**：先构建前端再打包镜像，避免 `//go:embed` 拿到空目录。

### 🔒 安全

- 移除写死的 root `123456` 密码：未设置 `INITIAL_ROOT_PASSWORD` 时用 `crypto/rand` 生成一次性随机密码并在启动日志打印一次。
- 注册开关不可被数据库回滚：受环境变量接管的 key 跳过数据库写入，并在每次加载后重新应用。
- `.dockerignore` 继续排除 `.env` / `.env.*`。

### 🔧 构建与发布

- 修复 `CGO_ENABLED=0` 交叉编译：ONNX embedding 通过 build tag 隔离，新增纯 Go stub，发布二进制与镜像不再依赖 cgo。
- 修复 Windows 发布二进制：`Daemonize()` 按平台拆分到 `daemon_unix.go` / `daemon_windows.go`。
- `release.yml` 的 Go 版本提升到 1.25，与 `go.mod` 对齐。

### ⚠️ 升级注意事项

- root 密码行为变更仅作用于全新部署（用户表为空）：不再固定 `123456`，请从启动日志取回随机密码并立即修改。
- 生产环境建议固定 `SESSION_SECRET`、`INITIAL_ROOT_PASSWORD`，并设置 `REGISTER_ENABLED=false`、`PASSWORD_REGISTER_ENABLED=false`。
- 发布前需在仓库配置 `DOCKERHUB_USERNAME` / `DOCKERHUB_TOKEN`，否则 `release-docker` 会主动失败。
- `CGO_ENABLED=0` 二进制不含本地 ONNX embedding；`MODEL_ROUTER_STRATEGY=cluster` 需配置 `EMBEDDING_PROVIDER=api`。
- 无数据库结构变更，无需迁移脚本。
