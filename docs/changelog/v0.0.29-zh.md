### ✨ 新增功能

- **模型别名与模型池**：新增个人别名与全局别名（超级管理员发布），单个别名最多 8 个候选模型、权重 1–1000，新会话按权重分配。支持 `X-Session-ID` 显式会话、基于消息历史的自动前缀识别、会话空闲 TTL、Redis 共享绑定与池内故障切换；日志同时保留业务别名与实际上游模型。详见[模型别名与模型池](../user/model-alias)。
- **原生多模态网关**：按“操作 + 执行模式”路由，新增 `wan2.6-t2i` 文生图、Wan2.7 图像编辑、`seed-tts-2.0` 语音合成、`qwen3-asr-flash` 原生语音识别、`gte-rerank-v2` 重排、`wan2.6-t2v` 异步视频生成，以及 Qwen Omni 双向实时语音 WebSocket 协议子集。详见[多模态网关总览](../media/overview)。
- **推理作业与持久账务**：同步与异步推理统一走额度预留 → 真实用量结算，支持 `GET /v1/inferences/:id` 查询原请求、`X-Inference-Id` 关联、未知结果保留待对账，并提供普通请求、视频任务、实时会话三类管理员对账接口。详见[账务结算与巡检](../media/settlement-probe)。
- **媒体资产与 worker**：视频资产落地本地目录、7 天有效期、512 MiB 单文件上限；worker 负责任务轮询、退避重试、资产清理与过期会话标记，多实例通过 SQL 租约协作。
- **控制台媒体探针调试台**：可直接对图像/音频渠道发起探测，探测结果记录管理员、操作、渠道与用量审计，不记录媒体 URL 或密钥。
- **渠道模型目录与映射**：渠道可声明默认模型与模型目录，支持模型映射（含目录模型名指向真实目标）；wildcard 令牌模型会展开为具体分组模型；启动时按渠道对账 ability，分组名从价格/渠道/用户合并真实名称。
- **可解释的路由失败诊断**：渠道失败时返回具体诊断原因，便于定位是权限、能力、地域还是上游错误。

### 🐛 问题修复

- 管理仪表盘聚合查询改为方言感知的条件计数与标识符引用，修复 PostgreSQL / SQLite 下保留字与布尔 `SUM` 表达式报错。
- 非管理员账号的模型别名作用域处理简化，避免错误暴露全局配置入口。
- 目录页模型与渠道列的展示顺序修正，使用示例与预置渠道模型清单补齐。

### 📚 文档

- 文档站新增「多模态与媒体」分类（总览、图像/语音/重排、视频/实时语音、账务结算与巡检）与「模型别名与模型池」页面，均提供中英双语。
- API 总览新增“多模态与媒体接口”索引；补充 v0.0.28 发布日志。

### ⚠️ 升级注意事项

- 无数据库结构变更，无需迁移脚本；别名与账务数据走既有表结构。
- 多实例部署时，API 与 worker 实例必须挂载**同一个**媒体资产目录共享卷，否则视频资产不可读。
- 新增价格按“每百万计量单位”配置：视频/ASR 以秒计价时需换算（0.00022 元/秒 = 每百万秒 220 元）。
- 视频任务必须提供 `Idempotency-Key`；实时语音是 Qwen 手动轮次协议子集，不保证兼容所有 OpenAI realtime 客户端。
- 别名池的会话分配比例不等于 Token 或采购金额比例，也不保证供应商缓存命中。
