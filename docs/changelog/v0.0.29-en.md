### ✨ New Features

- **Model aliases and pools**: personal and global aliases (global ones published by a super admin), up to 8 candidate models per alias with weights 1–1000, weighted selection for new sessions. Supports explicit `X-Session-ID`, automatic message-history prefix recognition, idle session TTL, Redis-shared bindings and in-pool failover; logs keep both the business alias and the actual upstream model. See [Model Aliases and Pools](../user/model-alias).
- **Native multimodal gateway**: routing by operation + execution mode, adding `wan2.6-t2i` text-to-image, Wan2.7 image editing, `seed-tts-2.0` TTS, `qwen3-asr-flash` native ASR, `gte-rerank-v2` rerank, `wan2.6-t2v` async video generation, and a Qwen Omni bidirectional realtime WebSocket protocol subset. See [Multimodal Gateway Overview](../media/overview).
- **Inference jobs and persistent billing**: sync and async inference share reserve → settle-on-real-usage accounting, with `GET /v1/inferences/:id` lookup, `X-Inference-Id` correlation, reservations kept for unknown outcomes, and dedicated admin reconciliation for plain requests, video jobs and realtime sessions. See [Settlement and Probes](../media/settlement-probe).
- **Media assets and worker**: video assets land in a local directory, valid for 7 days with a 512 MiB per-file cap; the worker handles job polling, backoff retries, asset cleanup and stale-session marking, coordinating across instances via SQL leases.
- **In-console media probe**: probe image/audio channels directly, recording admin, operation, channel and usage audit — never media URLs or keys.
- **Channel model catalog and mapping**: channels can declare default models and a model catalog, and map models (including catalog names pointing to real targets); wildcard token models expand to concrete group models; abilities reconcile from channels on startup, and group names merge real names from pricing/channels/users.
- **Explainable routing failures**: channel failures now return detailed diagnostic reasons, so you can tell permission, capability, region or upstream causes apart.

### 🐛 Fixes

- Admin dashboard aggregates now use dialect-aware conditional counts and identifier quoting, fixing reserved-word and boolean `SUM` failures on PostgreSQL / SQLite.
- Model alias scope handling for non-admin accounts simplified, so the global config entry is never exposed incorrectly.
- Catalog column ordering, usage examples and preset channel model lists corrected.

### 📚 Documentation

- New doc-site category "Multimodal & Media" (overview, image/audio/rerank, video/realtime, settlement & probes) plus a "Model Aliases and Pools" page, all bilingual.
- API overview gains a multimodal and media endpoint index; the v0.0.28 release notes were added.

### ⚠️ Upgrade notes

- No schema change and no migration script; aliases and billing reuse existing tables.
- With multiple instances, API and worker must mount the **same** shared media asset volume, or video assets become unreadable.
- New prices are configured per million metering units: second-billed video/ASR must be converted (0.00022 CNY/second = 220 CNY per million seconds).
- Video jobs require an `Idempotency-Key`; realtime voice is a Qwen manual-turn protocol subset and is not guaranteed compatible with every OpenAI realtime client.
- Alias pool weights are a session allocation ratio, not a token or spend ratio, and do not guarantee provider cache hits.
